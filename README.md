# TULIP Tourism Demand Forecasting

## Overview

This repository contains the work for our **Group Assignment on Tourism Demand Forecasting** using the public **TULIP Lab ISF-TDF2023 tourism demand dataset**.

The objective of the assignment is to build a **reproducible forecasting workflow** for tourism demand, evaluate forecasting performance using appropriate error measures, analyse selected destination markets, and generate the required final forecast submission.

The assignment consists of **7 mandatory questions divided into 3 parts**.

---

## Assignment Objectives

The main objectives are to:

* Build a reproducible tourism-demand forecasting workflow.

* Work with the public **TULIP Lab ISF-TDF2023** dataset.

* Forecast **20 destination series**.

* Generate monthly forecasts covering:

  **2023M08 to 2024M07**

* Compare and evaluate forecasting models using validation data.

* Analyse forecasting performance using **MASE** and **MAPE**.

* Perform detailed analysis for selected tourism markets.

* Generate the final forecast dataset in the required **wide format**.
